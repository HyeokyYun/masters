## 0. V2 vs V1 차이

| 구분 | V1 (docs/THESIS_PLAN.md) | V2 (본 문서) |
|---|---|---|
| 스코프 | 개별 점포 Growth/Stable/Decline 예측·진단 | 개별 예측 + **지역·도시 경제·인구와의 연계** |
| 중심축 | 신규 고객 유입 × 업력 | **매출 데이터 → 성장/하락/유지 예측 → 거시 지표** |
| 타깃 분야 | 소상공인 경제, 창업, IS analytics | 도시 경제학, 지역 경제, 정책과학, 기술경영 |
| 기여 범주 | Diagnostic framework | Diagnostic **+ 지역 경제 leading indicator 제안** |
| 외부 데이터 | 없음 | (옵션 B에서) 있음 |

## 1. 재정의된 연구 질문

### 큰 그림
> 소상공인의 주별 매출 거래 데이터로 개별 점포의 **성장·하락·유지**를 진단·예측할 수 있는가. 그리고 이 개별 예측을 지역 단위로 **집계**하면, 도시 경제·인구 동태를 설명하거나 선행하는 **leading indicator**로 기능할 수 있는가.

### 3단 구조 연구 질문

- **RQ1 (Micro)**: 주별 매출 거래 데이터에서 어떤 신호가 개별 점포의 성장·정체·하락을 구분·예측하는가?
- **RQ2 (Meso)**: 개별 점포의 상태를 **동·구 단위**로 집계한 "지역 경제 활력 지수(Local Economic Vitality Index, LEVI)"는 어떻게 설계되며, 어떤 공간 패턴을 보이는가?
- **RQ3 (Macro)**: LEVI는 **인구 이동, 고용, 상권 임대료, 공실률** 등 도시 경제 지표와 어떻게 관계 맺는가? 동시 상관인가, 선행/후행 관계인가?

### 기여 포지션 (기술경영 관점)
- **C1**: 거래 데이터 기반 소상공인 성장/하락/유지 진단·예측 프레임워크
- **C2**: 개별 예측을 지역 경제 지표로 집계하는 설계 (LEVI)
- **C3**: LEVI와 도시 경제·인구 지표의 관계 분석 → **정책·투자·창업 의사결정 지원** 함의

## 2. 두 가지 실행 옵션

### 옵션 A: 개념적·서술적 거시 확장 [낮은 리스크]

**내용**:
- Micro 분석(RQ1)은 기존 V1 자료 전량 활용
- Meso(RQ2) 집계 지표 LEVI는 **기존 KCD 데이터 내에서 동·구 단위 집계**로 구성 가능 → 신규 데이터 없음
- Macro(RQ3)는 **공개 통계(서울시 열린데이터, KOSIS) 중 이미 다운받기 쉬운 2-3개 지표**만 선택 → 간단 상관·시차분석
- Discussion에서 "도시 경제 leading indicator로의 활용 가능성"을 사례·개념적으로 논의

**장점**:
- 6-8주 내 완성 가능
- 기존 자산(figure·table·수치) 거의 그대로 재활용
- 외부 데이터 매칭에서 생길 수 있는 공간 단위 mismatch, 시차 mismatch 리스크 낮음
- 석사학위 "완성 우선"과 정합

**단점**:
- Macro 기여가 "시사·논의" 수준에 머무름
- 심사에서 "거시 주장을 뒷받침할 empirics가 부족하다"는 지적 가능

### 옵션 B: 실증적 거시 확장 [높은 리스크, 높은 기여]

**내용**:
- 옵션 A 전부 포함
- **추가로 외부 데이터 매칭**:
  1. 서울시 상권분석 서비스 (상권별 분기 매출/점포수/변화지표)
  2. 서울시 생활인구 / 통신사 유동인구
  3. 행정안전부 주민등록 인구 (동별 월간)
  4. 서울시 공실률·임대료 (소상공인시장진흥공단 / 서울시 통계)
  5. 통계청 고용률·자영업자 수 (구 단위)
- LEVI ↔ 거시 지표 간 동적 관계 실증 (Granger-style 시차 분석, 공간패널 회귀 등)

**장점**:
- 기여가 실증적으로 강함 → 향후 저널 확장 가능
- "기술경영" 관점에서 **데이터 기반 지역 경제 모니터링 시스템** 포지셔닝 강해짐

**단점**:
- 공간 단위 mismatch(동 vs 상권 vs 행정동) 해결 필요
- 시차 mismatch(주 vs 월 vs 분기) 해결 필요
- 각 데이터셋의 전처리·매칭·품질 검증에 추가 4-8주
- 전체 완성까지 3-5개월 추가

## 3. 권장안

**옵션 A를 우선 완성**하고, 심사 일정이 허락하면 옵션 B의 일부(예: 상권분석 서비스 1개, 생활인구 1개)만 추가하는 **하이브리드 경로**를 제안합니다.

이유:
- 사용자 목표가 "완성"
- 완성된 V1 자산이 Micro 전부를 커버 → 시간 대부분을 Macro 설계·집필에 투입 가능
- 심사 후 저널 확장 단계에서 외부 데이터 본격 매칭이 더 효율적

## 4. V2 논문 구조 (한글, 7장 구성, 65-90쪽 본문)

1. **서론** (6-8쪽)
   - 소상공인·도시경제·인구 변동의 상호작용 문제의식
   - 기존 소상공인 연구·도시 경제 지표·인구 연구의 3각 격차
   - RQ1-3 제시, 3단 구조 설명
   - 기여 및 논문 구성

2. **이론적 배경 및 선행연구** (10-14쪽)
   - 2.1 조직 생애주기 이론과 소상공인 연구
   - 2.2 도시 경제 leading indicator 연구 (금융·고용·부동산 지표)
   - 2.3 Digital trace / transaction-based regional analytics
   - 2.4 인구 이동·지역 경제의 상호작용 연구
   - 2.5 연구 격차 정리

3. **데이터** (6-8쪽)
   - 3.1 KCD 주별 거래 패널 (내부 데이터)
   - 3.2 Post-entry / Observed-window 표본 정의
   - 3.3 외부 공공 데이터 (옵션 A: 2-3개, 옵션 B: 5개) — **옵션 결정 후 확정**
   - 3.4 공간·시간 단위 매칭 규칙

4. **연구방법** (12-16쪽)
   - 4.1 전체 분석 프레임 (Micro → Meso → Macro)
   - 4.2 **Micro 레이어**: 개별 점포 Growth/Stable/Decline 레이블링·예측
     - 4.2.1 State 정의, 업력 bucket
     - 4.2.2 Feature 엔지니어링
     - 4.2.3 Multinomial logit / GBM 예측 모델
   - 4.3 **Meso 레이어**: LEVI 설계
     - 4.3.1 동·구 단위 집계 공식 (Growth share − Decline share 등)
     - 4.3.2 공간 표현 (choropleth)
     - 4.3.3 시간 동학 (주별 LEVI 시계열)
   - 4.4 **Macro 레이어**: LEVI와 도시·인구 지표의 관계
     - 4.4.1 상관·시차 상관
     - 4.4.2 (옵션 B에서만) 공간 패널 회귀
   - 4.5 Robustness 설계

5. **결과** (20-26쪽)
   - 5.1 Micro: 개별 점포 예측
     - 기존 Figure 1/2/3/S1 재활용
   - 5.2 Meso: LEVI 구축 결과
     - 동별 LEVI choropleth map
     - 구별 LEVI 분포와 이상치
     - 주별 LEVI 시계열
   - 5.3 Macro: LEVI ↔ 도시·인구 지표
     - 상관 매트릭스
     - 시차 상관 (LEVI가 선행하는가?)
     - (옵션 B에서만) 패널 회귀 결과
   - 5.4 Robustness
     - 레이블 컷오프·관측기간 민감도
     - 공간 단위 민감도 (동 vs 구)

6. **토의** (6-8쪽)
   - 6.1 이론적 기여 — 소상공인 dynamics × 지역 경제
   - 6.2 LEVI의 leading indicator 가능성
   - 6.3 정책·기술경영 시사점 — 상권 지원, 창업 타깃팅, 부동산 분석
   - 6.4 한계 — 단일 도메인(서울 외식업), 단일 기간, 인과 해석 불가
   - 6.5 향후 연구

7. **결론** (2-3쪽)

부록: feature 정의, hyperparameter, LEVI 공식 민감도, 지도 전장

## 5. 작업 순서

### Phase 1: 설계 확정 (이번 주)
- [x] 새 폴더 `thesis/` 생성
- [ ] **사용자 결정 — 옵션 A 또는 B (또는 하이브리드)**
- [ ] 결정 후 본 문서를 옵션-specific 버전으로 수정

### Phase 2: Meso 설계 (1-2주)
- LEVI 공식 시안 (3-4가지 후보) 작성
- 후보별 계산 스크립트 + 결과 비교
- 최종 LEVI 정의 확정

### Phase 3: Macro 분석 (2-3주)
- 외부 데이터 수집 (옵션에 따라 2-5종)
- 공간·시간 매칭
- 상관·시차·(패널) 분석

### Phase 4: 집필 (3-4주)
- Ch.3 데이터 → Ch.4 방법 → Ch.5 결과 → Ch.1 서론 → Ch.2 이론 → Ch.6 토의 → Ch.7 결론
- 국문·영문 초록, 참고문헌, 부록

### Phase 5: 심사 준비 (2주)
- 지도교수 피드백 반영
- 발표 자료 준비

## 6. 사용자 결정이 필요한 2가지

### 결정 1: 거시 확장의 실증 강도
- (A) 개념·서술적 — 공공 지표 2-3개로 간단 상관만
- (B) 실증적 — 외부 데이터 5종 매칭, 공간 패널 회귀
- (하이브리드, 권장) A로 완성 → 여유 시 B의 일부만 추가

### 결정 2: 거시 지표 선정 우선순위
본 논문에서 LEVI와 비교할 도시 경제·인구 지표 중 **가장 중요하다고 생각하는 1-2개**:
- [ ] 인구 이동 (동별 주민등록 전입/전출)
- [ ] 생활인구/유동인구 (서울시·통신사)
- [ ] 자영업자 수·폐업률 (KOSIS)
- [ ] 상가 임대료·공실률
- [ ] 고용률
- [ ] 부동산 거래량
- [ ] 기타 (명시)

우선순위가 분명하면 Macro 분석 scope를 빠르게 좁힐 수 있습니다.

## 7. 본 계획에서 **하지 않을** 것

- 인과 추정(DiD/IV/RD)의 본격 도입 — 석사 scope 초과
- 전국 또는 타 업종 확장 — 서울 외식업으로 고정
- 실시간 monitoring system 구축 — 분석·논문화에 집중
- LSTM·Transformer 등 deep sequence model 재학습 — 이미 V1에서 열위 확인됨
