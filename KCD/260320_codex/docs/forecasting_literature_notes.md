# 조기 예측·세일즈 포캐스트 문헌 기준 (작성 가이드)

개별미팅(2026-03-20)에서 요청: **30주(또는 50주) 관측만으로 생애주기·성장을 예측할 때 F1 ≈ 0.37 수준이 “높은지/낮은지”**  
금융 단기 수익 예측(포캐스팅)과는 문제 설정이 다르므로, 아래 축으로 문헌을 찾아 정리하면 논문에 논거로 쓰기 좋다.

## 검색 키워드 (영문)

- `retail sales forecasting` + `machine learning` + `accuracy`
- `SME` + `demand forecasting` + `small sample`
- `early classification` + `time series` + `partial observation`
- `company sales forecast` + `M5` or `M4` (competition) — 규모는 다르지만 스케일 감각용

## 정리할 항목 (템플릿)

| 항목 | 메모 |
|------|------|
| 논문/보고서 | 연도, 제목, 저널 |
| 예측 대상 | SKU, 매장, 매출, 수요 등 |
| 데이터 길이 | 예: 30주, 1년 등 |
| 지표 | MAPE, RMSE, F1, AUC 등 |
| 보고된 성능 수준 | 범위 |
| 본 연구와의 비교 가능성 | 동일/유사 여부 |

## 본 연구에서의 비고

- **분류 F1**이 아니라 **MAPE/RMSE**만 보고하는 매출 예측 문헌이 많으면, 비교 시 “지표가 다름”을 명시.
- 클래스 불균형이 크면 **F1·macro-F1·PR-AUC**를 함께 보면 설명이 안전함.
