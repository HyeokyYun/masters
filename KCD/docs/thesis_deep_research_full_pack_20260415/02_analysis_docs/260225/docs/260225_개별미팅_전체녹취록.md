## 녹취록에서 추출한 핵심 포인트

| 구분 | 내용 |
|------|------|
| **모델 디자인** | 로스 펑션 재정의, LSTM 활용 가능성 등 추가 검토 필요 |
| **클러스터링** | 논문의 한 부분으로 적합. 단, 전체는 회귀 등 포함 필요 |
| **회귀 분석** | "성공하는 업장이 왜 성공했는가" 설명 필수 |
| **4개 카테고리** | DUX(폭발적 성장), DUY(반등·유지), 평범, 망하는 |
| **DUX vs DUY** | DUX: 계속 상승, DUY: 상승 후 유지. 형태가 다름 |
| **샘플 수** | DUY·DUX 개수 확인 필요. 10~20개 수준이면 분석 어려움 |
| **Multinomial Logit** | 평범을 기준으로, 성공/실패 또는 DUX vs DUY 비교 가능 |
| **X변수** | 시계열 전체를 그대로 넣을 수 없음. **추출** 필요 |
| **X변수 예시** | new_customer_ratio 30주·반년 평균, 업력, 업종(식당·카페·술집 등) |
| **X변수 선택** | 잘 고르면 스토리가 풍부해짐 |
| **회귀 2가지** | (1) 전체 데이터, (2) 첫 30주만 사용 — 30주 변수가 중요하면 "초기 30주가 성공 예측" 주장 가능 |
| **Summary Statistics** | **회귀 전에** 클러스터별 요약 통계 표 제시. "업력 긴 업장이 특정 클러스터에 많았다" 등 |
| **회귀 X선정** | 요약 통계에서 클러스터 간 차이가 큰 변수를 X로 사용 |
| **예측** | 위 이해를 바탕으로 30주 예측까지 가면 완성도 상승 |
