## 2. 논문 서술 시 참고 수치

### 2.1 계량경제 회귀 (Step 3)

- **Model 1**: 주요 변수만 (new_customer_ratio, cv_sales_card)
- **Model 2**: Model 1 + 통제변수 (business_age_months, business_density, business_square_size)
- **Model 3**: Model 2 + 고정효과 (sigungu, depth_2 더미)

실제 계수·p-value는 `regression_tables_ols.csv`, `regression_tables_logit.csv` 참고.  
예: *"통제변수와 지역·업종 고정효과를 포함한 Model 3에서도 신규 고객 비율과 매출 변동성은 유의하였다 (p<0.01)."*

### 2.2 Event Study (Step 3b)

- 변곡점(inflection_week)을 t=0으로 정렬한 뒤 ±12주 구간에서 **신규 고객 비율(또는 4주 매출성장률 프록시)** 추이.
- **DUY(턴어라운드)** vs **DDZ(쇠퇴)** 그룹별로 추세가 어떻게 갈라지는지 시각화 (매출이 아닌 유입 지표로 동어반복 회피).
- `event_study_plots.png`: 변곡점 전후 **구조적 변화(Structural Break)** 및 그룹 간 차이.
- 논문 문장 예: *"사건 연구 결과, DUY 그룹은 변곡점 직전에 신규 유입이 급격히 증가하는 구조적 변화가 선행됨을 확인하였다."*

### 2.3 Ablation (Step 4) — 목적: 설명력 증명

- Step 4는 **미래 예측**이 아니라, UDX·변곡점 피처가 업장 최종 상태(성장/쇠퇴) 구분에 얼마나 **설명력(Feature Importance)**을 가지는지 증명하는 **Ablation Study**.
- **prediction_metrics.csv**: spec(base_only / base_udx_inflection) × model 별 accuracy, f1_score.
- **feature_importance_*_full.png**: full 모델(RF/XGB/LGB)에서 UDX_Code, P1_slope 등 기여도. **SHAP** 설치 시 `shap_summary_plot.png`, `shap_summary_xgboost.png` 등 생성.
- 논문 문장 예: *"Ablation 결과, UDX·변곡점 피처 추가 시 F1이 상승하였고, SHAP/변수중요도에서 P1_slope·final_code 등이 성장/쇠퇴 구분에 기여함을 확인하였다."*
