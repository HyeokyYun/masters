# 보강 실험 로드맵 (260223) — 계량경제학적 분석 보완

**배경**: 지금까지는 데이터 마이닝(패턴 발견: K-Shape, 변곡점)에 집중했다. 기술경영 분야 학위 논문을 위해 **"왜 이런 현상이 발생했는가"**를 통계적으로 증명하는 **정통 계량경제학적 분석(Econometric Analysis)**이 추가로 필요하다.

**목표**: "이런 패턴이 있다"에서 끝나지 않고, **"통제된 조건 하에서 어떤 변수가 생존과 쇠퇴를 결정짓는가?"**를 낱낱이 증명.

---

## 1. 논문 보강을 위해 "더 필요한" 핵심 실험 3가지

### ① 정통 계량경제학적 회귀분석 (Rigorous Econometric Regression)

기존 회귀는 예측 보조·단순 상관 확인에 가까웠다. 논문 핵심 챕터(보통 4장)를 위해 **교란 변수 통제 + 고정 효과**가 포함된 엄밀한 회귀가 필요하다.

| 항목 | 내용 |
|------|------|
| **종속 변수 (Y)** | 업장 최종 상태: (1) **Logit**: 1=성장형(X), 0=쇠퇴형(Z) 이진, 또는 (2) **OLS**: 전체 기간 `growth_rate` 연속값 |
| **주요 독립 변수 (X)** | `new_customer_ratio` (신규 고객 비율), `cv_sales_card` (매출 변동성) |
| **통제 변수 (Controls)** | `business_age_months`(업력), `business_density`(밀도), `business_square_size`(매장 크기) — 데이터에 있는 이름으로 매핑 필요 |
| **고정 효과 (Fixed Effects)** | 지역 `sigungu` 더미, 업종 `depth_2` 더미 — 지역/업종별 편차 통제 필수 |

**결과 도출**: 논문용 표에 **Model 1(기본) / Model 2(+통제변수) / Model 3(+고정효과)**를 나란히 배치하여, *"어떤 외부 요인을 통제하더라도 신규 고객 유입과 변동성 관리가 소상공인 생존에 유의미한 영향을 미친다 (p<0.01)"*를 증명.

---

### ② 변곡점 기준 사건 연구 (Event Study around Inflection Point)

변곡점을 분류 기준으로만 쓰지 말고, **사건 연구(Event Study)**로 활용한다.

| 항목 | 내용 |
|------|------|
| **정렬(Alignment)** | 각 업장의 **변곡점 발생 시점**을 t=0으로 정렬 |
| **분석 내용** | t=0 전후로 특정 구간(예: -w 주 ~ +w 주)에서 `new_customer_ratio` 또는 `avg_sales`의 **평균적인 흐름** 시각화 |
| **방어 논리** | "단순 회귀는 시점의 동적 변화를 잡지 못한다. 사건 연구를 통해, 턴어라운드(DU→U 등) 업장들은 변곡점 직전에 신규 유입이 급격히 증가하는 **구조적 변화(Structural Break)**가 선행됨을 확인했다." |

**산출물**: 변곡점 전후 시계열 그래프 (`event_study_plots.png` 등).

---

### ③ 머신러닝 기반 예측 및 SHAP 해석 (Advanced Prediction & Interpretability)

기본 회귀에서 RMSE가 개선된 신호를 머신러닝으로 고도화하고 **해석 가능성**을 더한다.

| 항목 | 내용 |
|------|------|
| **모델** | Random Forest, XGBoost, LightGBM 도입 |
| **피처 조합** | (1) 기본 피처(과거 매출 요약) vs (2) 기본 + UDX 피처 + 변곡점 피처(P1 기울기 등) |
| **해석 (SHAP)** | 예측 성능뿐 아니라 **SHAP Value** 추출 → "성장으로 예측할 때 변곡점 P1 기울기·신규 고객 비율이 얼마나 기여했는지" 시각화 (`shap_summary_plot.png` 등) |

**산출물**: `prediction_metrics.csv` (RMSE, F1 등), `shap_summary_plot.png`.

## 2. 4단계 파이프라인 (Step-by-Step 로드맵)

코드를 **4단계로 분리**하여 위에서 아래로 순차 실행되도록 세팅한다.

```
Step 1: Data Preprocessing     → df_base_features (마스터 테이블)
Step 2: Signal Extraction      → df_udx_labels (클러스터·변곡점·UDX)
Step 3: Econometric Analysis   → regression_tables, event_study_plots  ★ 신규
Step 4: Predictive Modeling   → prediction_metrics, shap_summary     ★ 보강
```

---

### Step 1: Data Preprocessing (데이터 전처리 및 기본 피처 엔지니어링)

| 항목 | 내용 |
|------|------|
| **Input** | 원본 `weekly_processed.parquet`, `meta_processed.csv` |
| **Action** | 결측치·이상치(Outlier) 제거; 업장별 142주 시계열 정렬; `new_customer_ratio`, `cv_sales_card`, `growth_rate` 등 파생 변수 생성 |
| **Output** | `df_base_features.csv` (모든 분석의 뼈대가 되는 마스터 테이블) |

**기존 매핑**: 260121 `regenerate_store_features.py`, 260204 run_01 → `store_features_for_analysis.csv`, `data_features_clean.parquet`. 260223에서는 이 출력을 **df_base_features** 규격으로 통일하거나, 1단계 전용 스크립트에서 동일 산출물 생성.

---

### Step 2: Signal Extraction (시계열 특성 추출: K-Shape & 변곡점)

| 항목 | 내용 |
|------|------|
| **Input** | 시계열 데이터 매트릭스 (Step 1 또는 원본 주별 피벗) |
| **Action** | **2-1.** K-Shape 군집화 (K=6, 스케일 정규화 포함) → 클러스터 라벨<br>**2-2.** Piecewise Regression → 업장별 변곡점(inflection_week), 전후 기울기 P1, P2<br>**2-3.** UDX 매핑 → 클러스터 + U/D 조합으로 12가지 생애주기 라벨 |
| **Output** | `df_udx_labels.csv` (클러스터, 변곡점, UDX 코드) |

**기존 매핑**: 260204 run_02 (K-Shape), 260204_gem run_01_inflection_p1p2 + step3_mapping → `store_cluster_labels_K6.parquet`, `inflection_p1p2_labels.csv`, `final_code_by_store_260121_outlier_removal.csv`. 260223에서는 이들을 **df_udx_labels** 한 테이블로 merge.

---

### Step 3: Econometric Analysis (원인 규명 — 논문 4장용) ★ 신규

| 항목 | 내용 |
|------|------|
| **Input** | `df_base_features.csv` + `df_udx_labels.csv` |
| **Action** | 통제 변수 + **지역(sigungu)·업종(depth_2) 고정 효과** 포함 **OLS / Logit** 실행; Model 1/2/3 결과를 학술 논문 포맷으로 저장; **Event Study**용 변곡점 전후 시계열 재정렬 및 그래프 출력 |
| **Output** | `regression_tables.csv` (또는 논문용 표 포맷), `event_study_plots.png` |

**구현 위치**: 260223 전용 스크립트 (예: `03_econometrics/run_regression_with_fe.py`, `run_event_study.py`).

---

### Step 4: Predictive Modeling (예측 및 활용 — 논문 5장용) ★ 보강

| 항목 | 내용 |
|------|------|
| **Input** | Step 1·2 산출물 결합 (기본 피처 + UDX·변곡점 피처) |
| **Action** | **Task**: 초기 30주(또는 특정 윈도우)만으로 미래 상태 예측.<br>**Models**: Baseline(이동평균 등) vs ML(RF, XGBoost, LightGBM).<br>**Ablation**: UDX·변곡점 피처 제거 시 vs 포함 시 성능(RMSE, F1) 비교.<br>**SHAP**: SHAP Value 계산 및 시각화. |
| **Output** | `prediction_metrics.csv`, `shap_summary_plot.png` |

**기존 매핑**: 260211 `run_prediction_80_20`, `run_regression_30w` 등. 260223에서는 RF/LightGBM 추가, UDX·변곡점 피처 명시적 ablation, SHAP 파이프라인 추가.
