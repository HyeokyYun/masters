## 1. 데이터 / 컴비네이션 카탈로그

- 원시: `original_data/weekly.parquet` (6.58M 점포-주차, 142주, 59,089 점포).
- 데이터 범위 2021-01-01 ~ 2023-08-28.
- 컴비네이션: `start_year × start_month × window_months × target_offset`.
- 후보 84개 중 80개가 데이터 범위 안 → panel/label/feature 모두 생성됨.
- 점포 수는 조합별로 29K – 37K (전체 표는 `outputs/tables/panel_summary.csv`).

## 2. 라벨 분포 관찰 (Step 02)

`outputs/tables/label_distribution.csv` 기준, 두 가지 패턴이 명확함.

1. **Target window가 데이터 끝(2023-08)에 가까울수록 Decline이 폭증.**
   예) `sy2022_sm08_w1m_off1` → Decline 0.675, `sy2021_sm07_w2m_off2`
   (target=2023-07~08) → Decline 0.629, `sy2021_sm06_w3m_off2`
   (target=2023-06~08) → Decline 0.512.
   2023-08은 데이터 컷오프 직전이라 누락 주차의 영향이 섞여 인공적 하락이
   잡힘. 본 분석에서는 **모델 비교 결론 근거로 쓰지 않고 sanity 결과로만 표시**.
2. **Jan-Mar / Sep-Nov 같은 비휴가/non-tail 시즌**에서 G/S/D가 더 균형
   (예) `sy2021_sm01_w3m_off1` G=0.566, S=0.356, D=0.078;
   `sy2021_sm09_w3m_off1` G=0.236, S=0.602, D=0.162;
   `sy2022_sm01_w3m_off1` G=0.514, S=0.432, D=0.054.
   step05의 메인 모델 비교는 이 구간에서 중점적으로 본다.

## 4. RF vs LightGBM

`seasonal_results_summary.csv`에서 같은 panel을 RF, LGB 모두 5-fold 평가.
대부분 panel에서 macro-F1 차이가 0.01 미만 (LGB가 살짝 안정적인 경향).
모델 선택은 본 결과에 결정적이지 않다.

## 5. 미팅 의도 대비 결론

- 교수가 요청한 "feature window와 target window의 캘린더 정렬"은 코드 수준에서
  완전히 구현됐고, 점포 수 / 라벨 분포 / 모델 학습 모두 합리적임.
- 시즈널리티 confound가 라벨 분포와 모델 정확도 양쪽 모두에 직접 보인다 →
  기존 `top_tier`의 "마지막 30주" 라벨이 항상 2023년 6–8월에 고정된 채
  학습되었다는 사실은 모델 정확도 해석을 왜곡할 수 있음. 시즈널 정렬 후에는
  같은 데이터로 macro-F1이 0.43–0.54 범위에 분산된다.
- 모델 정확도 자체는 시즈널 panel에서도 대체로 0.45–0.53 영역으로,
  legacy `top_tier`의 마지막-30주 baseline과 비교했을 때 동등하거나 약간
  낮음. 시즈널리티 통제의 가치는 정확도 향상이 아니라 **신호 해석의 정당성**
  확보다.
